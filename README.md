# Patient Management System

## 1. Project Description

The Patient Management System is a simple web-based application developed using HTML, CSS, and JavaScript.

The main purpose of this project is to manage patient information easily. It allows users to add, view, update, and delete patient records using CRUD operations.

https://chelurusandhya-bot.github.io/patientmanagementsystem/

## 2. Technologies Used

- HTML – To create the webpage structure.
- CSS – To design and style the application.
- JavaScript – To implement CRUD operations.
- LocalStorage – To store patient details in the browser.

## 3. Features

- Add new patient details.
- View all patient records.
- Update existing patient information.
- Delete patient records.
- Store data using browser LocalStorage.
- Simple and user-friendly interface.

## 4. CRUD Operations

| Operation | Description |
|---|---|
| Create | Add new patient details |
| Read | Display patient records |
| Update | Edit patient information |
| Delete | Remove patient records |

## 6. How to Run the Project

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Make sure all three files are in the same folder.
4. Open `index.html` in your browser.
5. Enter patient details.
6. Click the Add Patient button.
7. Use Edit and Delete buttons to manage patient records.
